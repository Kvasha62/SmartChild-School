## 4. Определение состояния L-02 и выбор формулировки (NC-13)

### 4.1. Два разных сведения

Состояние L-02 определяется двумя независимыми сведениями, которые нельзя подменять одно другим:

1. **Наличие доказательства решения владельца** — дословная цитата решения, дата и полный 40-символьный SHA версии, к которой решение относится.
2. **Текстовый статус записи** — значение `предложено`, `принято`, `отклонено` или `заменено` в `docs/decisions/README.md`.

Статус `принято` без доказательства не образует состояние C. Доказательство без повышенного статуса не образует состояние C и не даёт исполнителю права повысить статус самостоятельно.

### 4.2. Процедура определения

1. Зафиксировать полный SHA `main`, дату и время проверки.
2. Прочитать `docs/decisions/README.md` на этом SHA: наличие записи L-02, её текстовый статус, наличие цитаты решения и полного SHA в доказательстве.
3. Прочитать основной документ на том же SHA: состояние строки L-02 в §7 и применяемую формулировку строки 6.
4. Сопоставить сведения с таблицей §4.3.
5. Если комбинация не входит в таблицу — остановиться по правилу §4.5.
6. Зафиксировать результат: состояние, применимая формулировка, SHA и время проверки.

Все три чтения выполняются на **одном и том же** SHA. Смешивать документы с разных коммитов запрещено.

- статус `принято` с доказательством, но строка открыта;
- статус `предложено`, но строка открыта;
- статус `отклонено` или `заменено` — вне матрицы; требует отдельного решения владельца.

### 4.5. Порядок при расхождении

| Расхождение | Действие |
| --- | --- |
| **D1.** Статус `принято`, доказательства нет | Не считать состоянием C. Остановиться; не применять формулировку (i); сообщить владельцу; изменение статуса — только владелец |
| **D2.** Доказательство есть, статус `предложено` | Если строка §7 закрыта — текстовое состояние B; формулировка (iii) истинна, поскольку не утверждает значения статуса. Если строка открыта — D5. Повышение статуса — только владелец; если задача требует согласованности, остановиться |
| **D3.** Статус `принято` с доказательством, строка открыта | Несогласованное состояние. Остановиться до отдельного решения владельца |
| **D4.** Запись отсутствует, строка закрыта | Несогласованное состояние. Остановиться |
| **D5.** Любая иная комбинация | Несогласованное состояние. Остановиться |

Во всех случаях D1—D5 исполнитель не изменяет запись, не выставляет статус и не выбирает формулировку «по смыслу»; он фиксирует расхождение и передаёт решение владельцу.

### 4.6. Полномочия

- Исполнитель **не вправе** менять статус записи L-02, добавлять доказательство, удалять запись или создавать её заново.
- Исполнитель **не вправе** закрывать строку §7 без отдельного разрешения владельца на изменение основного документа.
- Исполнитель **вправе** только определить состояние по §4.2 и применить соответствующую формулировку и правку в пределах разрешённого объёма.

### 4.7. Момент определения

Формулировка выбирается по проверенному состоянию целевой базы **непосредственно перед реализацией**. Результаты более ранних проверок, включая проверки версий 1—6 и отчёты ревью, доказательством текущего состояния не являются. Перед применением правки повторяются шаги §4.2; в отчёте указываются SHA, дата и время.
