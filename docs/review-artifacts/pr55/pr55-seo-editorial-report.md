## 3. SEO

### 3.1. Интент и запросы

- **Основной запрос:** «как установить python и vs code».
- **Дополнительные фразы:** установка python; установка vs code для python; python для начинающих; настройка vs code для python; первая программа на python; как запустить python программу; python hello world.
- **Интент:** информационный, формат «сделай сейчас»: пользователь хочет получить рабочую среду и увидеть результат, а не читать теорию.

Интент выведен из состава выдачи по запросу об установке Python и VS Code для начинающих (2026-10-23): в результатах доминируют пошаговые руководства, объединяющие установку обеих программ, настройку расширения и запуск первой программы, — [VS Code: Getting Started with Python](https://code.visualstudio.com/docs/python/python-tutorial), [Microsoft Learn: Python на Windows для начинающих](https://learn.microsoft.com/ru-ru/windows/python/beginners), а также русскоязычные пошаговые инструкции. Это наблюдение о структуре выдачи, а не измерение спроса.
