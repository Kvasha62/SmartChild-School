- Полный отчёт существует в двух местах: в описании PR (по L-02) и в
  исходном неотслеживаемом файле
  `docs/reviews/protocol-continuity-implementation-report-2026-11-14.md`.
  Исходный файл не удалялся; его удаление или замена возможны только после
  подтверждения полноты текста в PR и отдельного разрешённого изменения.
- Каталог `docs/reviews/` уже содержит другие файлы, что шире расхождения
  с L-02; это не создаёт разрешения и требует отдельного решения.
- Реальное использование протокола Copilot, DeepSeek и другими моделями не
  проверялось в их рабочих средах.
- Локально приложение, Django, SQL, Docker и тесты не запускались.
- GitHub Actions автоматически выполнил workflow «Django and Wagtail CI»
  на исходном HEAD `bf949e9…` (run 43563720488): Django-проверки, PostgreSQL,
  миграции, тесты и Docker smoke-test; job `test` — success. CI не заменяет
  локальную проверку и не означает принятие протокола. Результат CI для
  ревизии исправлений указан в проверках PR.

## Следующий конкретный шаг

Ревьюер проверяет обновлённый PR по актуальному полному SHA; владелец явно
фиксирует решение по этому же SHA. До решения не сливать PR, не объявлять
протокол принятым и не расширять разрешения на реализацию или production.
