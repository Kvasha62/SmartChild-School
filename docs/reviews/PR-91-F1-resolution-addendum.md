# Дополнение к независимому ревью PR #91: устранение F-1

Дата проверки: 2026-11-03

## 1. Назначение

Это дополнение фиксирует устранение замечания F-1 из независимого ревью вложенного содержимого StreamField.

Первоначальное замечание касалось невозможности однозначно связать результаты тестирования с неизменяемой версией реализации: тесты выполнялись на рабочем дереве с незакоммиченными изменениями, а полный снимок этого дерева не был зафиксирован.

Настоящее дополнение не изменяет исходный отчёт задним числом и не распространяет выводы на функциональность, не входившую в предмет проверки.

## 2. Идентификация реализации

Реализация зафиксирована отдельным коммитом:

- Ветка: `feature/nested-streamfield-implementation`

- Базовый коммит: `6501c580f5ada90baa361a030769b492558e08f7`

- Коммит реализации: `bb81c950c62a7471adb8418870ca505f8b22039f`

- Tree SHA: `eeecfa4bc3cba0a95c3b0b03e6c3c2e660bf0aff`

- Сообщение: `feat: add nested lesson StreamField migrations`

- **Публичная ссылка на неизменяемый коммит:** https://github.com/Kvasha62/SmartChild-School/commit/bb81c950c62a7471adb8418870ca505f8b22039f

- **Публичная ветка с этим коммитом:** https://github.com/Kvasha62/SmartChild-School/tree/feature/nested-streamfield-implementation

После публикации ветки GitHub API независимо подтвердил, что её HEAD равен `bb81c950c62a7471adb8418870ca505f8b22039f`, а Tree SHA равен `eeecfa4bc3cba0a95c3b0b03e6c3c2e660bf0aff`. Следовательно, рецензенты могут получить именно тот неизменяемый снимок исходного кода, на котором выполнялись проверки.

Дерево коммита в точности совпало с SHA дерева, полученным до создания коммита посредством `git write-tree`.

Коммит содержит ровно 10 файлов:

2. `school/static/school/js/lesson-tabs.js`

3. `school/templates/school/blocks/lesson_body.html`

4. `school/templates/school/blocks/tabs.html`

5. `school/test_migrations.py`

6. `school/tests.py`

7. `school/migrations/0005_accordion_stream_content.py`

8. `school/migrations/0006_alter_lessonpage_body.py`

9. `school/test_accordion_content_migration.py`

10. `school/test_nested_content_migration.py`

Итоговый состав коммита: 1 678 добавлений и 100 удалений.

SEO-изменения в этот коммит не включены. Они остались отдельными незакоммиченными изменениями рабочей копии.

## 4. Границы доказательств

Ранее в ходе работы отдельно выполнялись применение миграций 0001–0006, откат миграций 0005 и 0006 и повторное применение на временной базе данных `smartchild_migrations_review_20261102`.

Этот цикл завершился успешно, однако он был выполнен до создания неизменяемого коммита. Поэтому в настоящем дополнении он не используется как самостоятельное доказательство выполнения миграционного цикла именно на коммите `bb81c950...`.

Настоящее подтверждение F-1 основано на точной идентификации коммита и повторных тестах, Django checks и проверке согласованности миграций после его создания.

## 5. Оценка замечания F-1

**Статус: RESOLVED.**

Причина устранения:

- ранее проверенное состояние рабочего дерева получило точную идентификацию через SHA Git tree;

- это дерево зафиксировано неизменяемым коммитом;

- SHA дерева коммита совпадает с SHA ранее проверенного дерева;

- после создания коммита целевые и полные тесты были повторно выполнены успешно;

- проверки Django и согласованности миграций также прошли на зафиксированной реализации;

- точный коммит и ветка опубликованы в GitHub и доступны рецензентам для независимого получения и проверки исходного снимка.

Таким образом, теперь существует проверяемая связь между конкретной версией реализации и результатами повторных проверок, а исходный код этого снимка доступен по постоянной ссылке.
