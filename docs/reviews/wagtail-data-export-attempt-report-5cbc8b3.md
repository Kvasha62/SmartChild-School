## 4. Минимальный доступ или файл, требуемый от владельца

**Факт.** Для продолжения достаточно одного из:

1. **Файл экспорта** в репозитории или рабочей области, содержащий только необходимые для инвентаризации сведения: page ID, тип страницы, title/slug, parent ID/type, `url_path` и публичный URL (если доступны), статус публикации и ограничения, `direction`, topic ID/title/slug, сведения для проверки связей/конфликтов/полноты.  
2. **Read-only доступ к базе** (staging предпочтительно): параметры подключения для пользователя с правами только на чтение (SELECT) — без права на изменение данных, миграции или публикацию.
