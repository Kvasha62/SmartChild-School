## 3. Проверенные свойства

### 3.1 Только чтение

Команда формирует выборку `Page.objects.live().public().specific().order_by("path")`, извлекает данные страниц и собирает отчёт. В просмотренной реализации нет операций сохранения моделей, изменения страниц, публикации, удаления или изменения настроек Wagtail.

### 3.2 Область публичных страниц

Выборка ограничена опубликованными и публичными страницами. В тестах проверяется включение публичного опубликованного урока и исключение черновика и страницы с ограничением LOGIN.

### 3.3 SEO-метаданные

- Эффективный заголовок для проверки выбирается по правилу `seo_title` → `title`, соответствующему базовому шаблону.
- Повторяющиеся заголовки нормализуются по пробелам и регистру.
- Дублирующиеся явно заданные `search_description` выявляются отдельно.
- Урок без явного описания и `intro` помечается как использующий общий fallback, что согласуется с контрактом PR #71.

### 3.4 Изображения в rich text

HTML разбирается через стандартный `HTMLParser`; учитываются `img` и Wagtail embeds с `embedtype="image"`. Отсутствующий атрибут `alt` создаёт finding для ручной проверки, а явно пустой `alt` не объявляется дефектом автоматически. Это корректно сохраняет возможность помечать декоративные изображения.

### 3.5 Формат и воспроизводимость

JSON-отчёт сериализуем, список страниц и findings сортируется; текстовый вывод включает количество страниц и находок. Проверены тесты на общий fallback, изображения, закрытые/черновые страницы и дубли метаданных.
