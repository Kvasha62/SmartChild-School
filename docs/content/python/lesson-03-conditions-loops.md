## 2. Сравниваем значения

Операторы сравнения проверяют отношение между двумя значениями. Результатом сравнения будет логическое значение: `True` (истина) или `False` (ложь).

| Оператор | Значение | Пример |
| --- | --- | --- |
| `==` | Равно | `age == 12` |
| `!=` | Не равно | `age != 12` |
| `>` | Больше | `score > 5` |
| `<` | Меньше | `score < 5` |
| `>=` | Больше или равно | `age >= 18` |
| `<=` | Меньше или равно | `age <= 18` |

Пример:

```python
age = 12

print(age >= 18)
print(age < 18)
```

Ожидаемый вывод:

```text
False
True
```

Не путай `=` и `==`: один знак присваивает значение переменной, два знака сравнивают значения.

## 3. Выбираем действие с помощью `if`

Иногда программа должна выполнить команду только при определённом условии. Для этого используется `if`:

```python
age = 15

if age >= 18:
    print("Ты совершеннолетний.")
```

В этом примере сообщение не появится, потому что значение `age` меньше 18.

Если условие истинно, Python выполняет команды внутри блока. Блок выделяется отступом. Двоеточие после условия обязательно.

Добавим альтернативу с `else`:

```python
age = 15

if age >= 18:
    print("Ты совершеннолетний.")
else:
    print("Ты ещё несовершеннолетний.")
```

Ожидаемый вывод:

```text
Ты ещё несовершеннолетний.
```

Блок `else` выполняется, если условие в `if` ложно.

## 4. Несколько вариантов: `elif`

Если нужно проверить несколько вариантов по порядку, используй `elif`:

```python
score = 8

if score >= 9:
    print("Отлично")
elif score >= 7:
    print("Хорошо")
elif score >= 5:
    print("Нужно повторить материал")
else:
    print("Начни с основ и попробуй ещё раз")
```

Ожидаемый вывод:

```text
Хорошо
```

Python проверяет условия сверху вниз и выполняет первый подходящий блок. После этого остальные варианты в этой цепочке пропускаются. Поэтому порядок условий важен: более строгие условия обычно ставят выше менее строгих.

## 5. Объединяем условия

Логические операторы позволяют составлять более сложные проверки.

- `and` — оба условия должны быть истинными;
- `or` — достаточно, чтобы истинным было хотя бы одно условие;
- `not` — меняет истинность условия на противоположную.

Пример с `and`:

```python
age = 14
has_permission = True

if age >= 13 and has_permission:
    print("Можно продолжить.")
else:
    print("Условия не выполнены.")
```

Ожидаемый вывод:

```text
Можно продолжить.
```

Пример с `or`:

```python
day = "суббота"

if day == "суббота" or day == "воскресенье":
    print("Выходной")
else:
    print("Учебный или рабочий день")
```

Условия можно проверять и на вводе пользователя. Помни, что `input()` возвращает строку, поэтому возраст из ввода нужно преобразовать в число:

```python
age = int(input("Сколько тебе лет? "))

if age >= 18:
    print("Доступ разрешён.")
else:
    print("Доступ пока закрыт.")
```

Вводи целое число. Обработку нечислового ввода мы изучим позже.

## 6. Цикл `for`: повторяем известное число раз

Цикл `for` удобно использовать, когда известно, сколько раз нужно выполнить действие.

```python
for number in range(5):
    print(number)
```

Ожидаемый вывод:

```text
0
1
2
3
4
```

`range(5)` создаёт последовательность чисел от 0 до 4. Верхняя граница не включается в последовательность.

Если нужно вывести числа от 1 до 5, напиши:

```python
for number in range(1, 6):
    print(number)
```

Ожидаемый вывод:

```text
1
2
3
4
5
```

Общая форма `range(start, stop)` включает начальное значение `start`, но не включает `stop`.

### Пример: таблица умножения на 3

```python
for number in range(1, 6):
    print(f"3 × {number} = {3 * number}")
```

Ожидаемый вывод:

```text
3 × 1 = 3
3 × 2 = 6
3 × 3 = 9
3 × 4 = 12
3 × 5 = 15
```

## 7. Цикл `while`: повторяем, пока условие истинно

Цикл `while` повторяет блок, пока его условие истинно:

```python
count = 1

while count <= 3:
    print("Повтор", count)
    count = count + 1
```

Ожидаемый вывод:

```text
Повтор 1
Повтор 2
Повтор 3
```

В каждой итерации значение `count` увеличивается на 1. Когда `count` станет равным 4, условие `count <= 3` станет ложным и цикл завершится.

**Важно:** внутри цикла `while` следи, чтобы условие в какой-то момент стало ложным. Если значение, от которого зависит условие, никогда не меняется, программа может зациклиться и продолжать работу бесконечно. Чтобы остановить такой запуск в терминале, обычно нажимают `Ctrl+C`.

## 8. Мини-проект: угадай число

Пока программа не будет загадывать случайное число: сначала сделаем простую версию с заранее заданным ответом. Это позволит сосредоточиться на условиях и цикле.

```python
secret_number = 7
guess = int(input("Угадай число от 1 до 10: "))

while guess != secret_number:
    if guess < secret_number:
        print("Слишком мало.")
    else:
        print("Слишком много.")

    guess = int(input("Попробуй ещё раз: "))

print("Верно! Ты угадал.")
```

Пример диалога:

```text
Угадай число от 1 до 10: 4
Слишком мало.
Попробуй ещё раз: 9
Слишком много.
Попробуй ещё раз: 7
Верно! Ты угадал.
```

Программа продолжает просить число, пока введённое значение не совпадёт с `secret_number`. Внутри цикла условие `if` помогает подсказать, в какую сторону изменить догадку.

Для этого примера вводи целые числа. Если ввести текст вместо числа, преобразование через `int()` завершится ошибкой.

## 11. Частые ошибки

### Ошибка 1. Один знак равенства вместо двух

Неправильно:

```python
if age = 18:
    print("18 лет")
```

Правильно:

```python
if age == 18:
    print("18 лет")
```

В условии сравнения используется `==`.

### Ошибка 2. Нет отступа после условия или цикла

Неправильно:

```python
if score >= 5:
print("Зачёт")
```

Правильно:

```python
if score >= 5:
    print("Зачёт")
```

Команды внутри блока должны иметь отступ.

### Ошибка 3. Неверная верхняя граница `range()`

`range(1, 5)` выдаёт числа 1, 2, 3, 4 — число 5 не включается. Чтобы получить числа от 1 до 5, используй `range(1, 6)`.

### Ошибка 4. Цикл `while` не заканчивается

Проверь, меняется ли внутри цикла значение, от которого зависит условие. Убедись, что условие сможет стать ложным.
