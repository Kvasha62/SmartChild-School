## 1. Зачем нужны Python и VS Code: обзор инструментов

Этот раздел только знакомит с инструментами. **Не выполняй установку дважды:** конкретные шаги для твоей системы приведены в разделах 2–4.

- **Python** — язык программирования, на котором мы будем писать программы.
- **Visual Studio Code (VS Code)** — редактор, в котором удобно создавать и запускать файлы с кодом.
- **Расширение Python для VS Code** — добавляет поддержку Python в редактор.

VS Code, сам Python и расширение Python — три отдельных компонента. Редактор не содержит Python внутри, а расширение не заменяет интерпретатор: именно интерпретатор выполняет код. Поэтому установить нужно все три части, и дальше мы так и сделаем.

Официальные сайты:

- VS Code — [code.visualstudio.com](https://code.visualstudio.com/)
- Python — [python.org/downloads](https://www.python.org/downloads/)

## 2. Установка Python и VS Code в Windows 10 и Windows 11

### Шаг 1. Установи VS Code в Windows

1. Открой [code.visualstudio.com](https://code.visualstudio.com/).
2. Скачай установщик для Windows.
3. Запусти его, прими условия лицензии и заверши установку. Если не знаешь, что выбрать, оставь стандартные параметры.

### Шаг 2. Установи Python в Windows

1. Открой [python.org/downloads](https://www.python.org/downloads/).
2. Нажми кнопку скачивания рекомендуемой версии для Windows и запусти установщик.
3. Если установщик предлагает добавить Python в `PATH`, это может быть удобно для команды `python`. Но **для этого урока это необязательно**: далее мы используем команду `py`, которая обычно устанавливается вместе с официальным установщиком Python для Windows. Команда `py -3` запускает Python через лаунчер Windows и обычно работает независимо от настройки `PATH`. Добавление Python в `PATH` позволяет запускать его командой `python` и может упростить обнаружение интерпретатора в VS Code. Если VS Code не находит Python автоматически, можно выбрать установленный интерпретатор вручную.
4. Заверши установку.

### Шаг 3. Проверь Python в Windows

Открой «Терминал» или «Командную строку» через меню «Пуск». Выполни:

```powershell
py -3 --version
```

Нажми Enter. Если Python доступен, появится строка с версией, например `Python 3.x.x`. Буквы `x` здесь обозначают номер установленной версии.

Если команда не распознана, проверь, что установка завершилась, затем закрой и заново открой терминал. Если проблема остаётся, воспользуйся инструкциями по установке на официальном сайте Python.

## 3. Установка Python и VS Code в Ubuntu и Linux

Названия программ и команды установки зависят от дистрибутива. Команды ниже предназначены для Ubuntu и других систем на базе Debian, использующих `apt`.

### Шаг 1. Проверь Python в Ubuntu и Linux

Открой терминал и выполни:

```bash
python3 --version
```

Если команда выводит версию Python 3, переходи к шагу 2. Если Python отсутствует, в Ubuntu установи его командами:

```bash
sudo apt update
sudo apt install python3 python3-venv python3-pip
```

Система может запросить пароль пользователя. При вводе пароля символы на экране могут не отображаться — это нормально. Пакет `python3-venv` нужен для создания изолированных окружений Python, а `python3-pip` — для установки сторонних библиотек. В первой программе они не используются, но понадобятся в следующих уроках.

Для других дистрибутивов используй пакетный менеджер и документацию своей системы.

### Шаг 2. Установи VS Code в Linux

1. Открой [code.visualstudio.com](https://code.visualstudio.com/).
2. Выбери пакет или способ установки для своего дистрибутива.
3. Следуй актуальным инструкциям на официальном сайте.

### Шаг 3. Проверь Python после установки

В терминале выполни:

```bash
python3 --version
```

Убедись, что команда показывает версию Python 3.

## 4. Установка Python и VS Code в macOS

### Шаг 1. Установи VS Code в macOS

1. Открой [code.visualstudio.com](https://code.visualstudio.com/).
2. Скачай версию для macOS.
3. Распакуй архив, если это необходимо, и перемести Visual Studio Code в папку «Программы».
4. Запусти VS Code.

### Шаг 2. Установи Python в macOS

1. Открой [python.org/downloads](https://www.python.org/downloads/).
2. Выбери установщик для macOS и следуй его инструкциям.

Для обучения используй Python, установленный с python.org, а не системный Python macOS: системная версия предназначена для нужд операционной системы и не рассчитана на учебные эксперименты.

### Шаг 3. Проверь Python в macOS

Открой «Терминал» через Spotlight и выполни:

```bash
python3 --version
```

Если команда показывает версию Python 3, переходи к следующему разделу.

**Возможная особенность macOS:** при первом запуске некоторых команд разработчика система может предложить установить Xcode Command Line Tools. Это системные инструменты разработчика. Если такое окно появилось, прочитай его текст и следуй официальным инструкциям Apple. Дождись завершения установки, затем снова выполни `python3 --version`. Если команда по-прежнему не работает, проверь сообщение об ошибке и следуй официальным инструкциям Apple. Если Python установлен с python.org, не нужно устанавливать дополнительные инструменты без причины. Не удаляй и не заменяй вручную системные компоненты Python.

## 5. Настройка VS Code для Python: расширение и интерпретатор

### Шаг 1. Установи расширение Python

1. Запусти VS Code.
2. Открой раздел Extensions («Расширения») в боковой панели.
3. Найди расширение **Python** от Microsoft.
4. Нажми Install («Установить»).

### Шаг 2. Выбери интерпретатор

Если VS Code не выбрал Python автоматически:

1. Открой палитру команд: `Ctrl+Shift+P` в Windows/Linux или `Cmd+Shift+P` в macOS.
2. Найди команду `Python: Select Interpreter`.
3. Выбери установленный Python 3.

Если нужный интерпретатор не появился, сначала проверь, что Python запускается в терминале. Затем перезапусти VS Code и повтори выбор интерпретатора.

## 6. Создаём проект `python-start` и файл `hello.py`

1. Создай папку с названием `python-start`, например в папке «Документы».
2. В VS Code выбери **File → Open Folder** (Файл → Открыть папку) и открой `python-start`.
3. В панели файлов создай новый файл с названием `hello.py`.

Расширение `.py` используется для файлов с кодом Python.

## 7. Первая программа на Python: `print()` и кавычки

Вставь в файл `hello.py`:

```python
print("Привет, мир!")
```

Сохрани файл: `Ctrl+S` в Windows/Linux или `Cmd+S` в macOS.

`print()` выводит значение на экран. Кавычки обозначают текстовую строку: текст внутри кавычек выводится как есть, а сами кавычки в результате не появляются. Кавычки в коде обязательны, если мы хотим передать текст.

## 8. Как запустить программу на Python

В VS Code можно нажать кнопку запуска Python-файла (значок ▶, если он отображается над редактором). Также можно запустить программу из встроенного терминала через меню **Terminal → New Terminal**.

Сначала убедись, что терминал открыт в папке проекта. Затем выполни подходящую команду.

**Windows:**

```powershell
py hello.py
```

**Ubuntu/Linux и macOS:**

```bash
python3 hello.py
```

Ожидаемый результат:

```text
Привет, мир!
```

Если вывод совпал, программа запустилась успешно.

## 9. Если что-то не работает: частые ошибки

### Терминал не находит Python

- Windows: проверь командой `py -3 --version`.
- Ubuntu/Linux и macOS: проверь командой `python3 --version`.
- После установки закрой и заново открой терминал.
- Если VS Code не видит Python, перезапусти VS Code и выполни `Python: Select Interpreter`.

### Программа не запускается

Проверь, что:

- файл называется `hello.py`;
- файл сохранён;
- терминал открыт в папке проекта;
- команда запуска соответствует твоей операционной системе;
- скобки и кавычки написаны правильно.

Правильный пример:

```python
print("Привет, мир!")
```

Если ошибка остаётся, скопируй её полный текст для разбора. Не публикуй пароли, токены или персональные данные в сообщениях об ошибках.

## 12. Частые вопросы (FAQ)

### Нужно ли устанавливать Python, если я уже установил VS Code?

Да, нужно. VS Code — это редактор, в нём нет самого Python. Расширение Python тоже не включает интерпретатор: оно только добавляет поддержку языка в редактор.

### Какую версию Python выбрать новичку?

Подойдёт любая актуальная версия Python 3, которую предлагает python.org по кнопке скачивания. Для этого урока конкретный номер версии не важен: все команды работают одинаково.

### Почему в Windows используется команда `py`, а в Linux и macOS — `python3`?

Так исторически сложилось: в Windows официальный установщик Python добавляет программу запуска `py`, а в Linux и macOS стандартная команда для третьей версии языка — `python3`. Команда `python` в этих системах может отсутствовать или указывать на другую версию.

### Что делать, если после установки терминал всё равно не находит Python?

Закрой и заново открой терминал: он читает настройки системы при запуске. Если VS Code был открыт во время установки, перезапусти и его, затем выбери интерпретатор командой `Python: Select Interpreter`.

### Нужны ли права администратора?

Обычно да: установка программ в Windows и macOS требует подтверждения, а в Ubuntu команды установки запускаются через `sudo`. Если прав нет, используй инструкции официальных сайтов для установки без администратора.

### Можно ли выполнить этот урок в онлайн-редакторе без установки?

Нет. Цель урока — настроить собственную среду и запустить программу локально, поэтому установка VS Code и Python обязательна.
