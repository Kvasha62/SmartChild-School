## 1. Зачем нужны Python и VS Code: обзор инструментов

Этот раздел только знакомит с инструментами. **Не выполняй установку дважды:** конкретные шаги для твоей системы приведены в разделах 2–4.

- **Python** — язык программирования, на котором мы будем писать программы.
- **Visual Studio Code (VS Code)** — редактор, в котором удобно создавать и запускать файлы с кодом.
- **Расширение Python для VS Code** — добавляет поддержку Python в редактор.

VS Code, сам Python и расширение Python — три отдельных компонента. Редактор не содержит Python внутри, а расширение не заменяет интерпретатор: именно интерпретатор выполняет код. Поэтому установить нужно все три части, и дальше мы так и сделаем.

Официальные сайты:

- VS Code — [code.visualstudio.com](https://code.visualstudio.com/)
- Python — [python.org/downloads](https://www.python.org/downloads/)

## 2. Установка Python и VS Code в Windows 10 и Windows 11

**Совместимость:** Python install manager в формате MSIX требует Windows 10 версии 21H2 (сборка 19044) или новее. Если у тебя более ранняя сборка Windows 10, MSIX может не установиться. Проверь системные требования и доступные варианты на [официальной странице выпусков Python для Windows](https://www.python.org/getit/windows/): там могут быть доступны традиционные установщики Python. Перед скачиванием проверь требования именно выбранного выпуска.

### Шаг 1. Установи VS Code в Windows

1. Открой [code.visualstudio.com](https://code.visualstudio.com/).
2. Скачай установщик для Windows.
3. Запусти его, прими условия лицензии и заверши установку. Если не знаешь, что выбрать, оставь стандартные параметры.

### Шаг 2. Установи Python в Windows

1. Открой [python.org/downloads](https://www.python.org/downloads/).
2. Скачай **Python install manager** — официальный инструмент Python для установки и управления версиями Python в Windows — с [python.org/downloads](https://www.python.org/downloads/) или установи его из Microsoft Store. Если ты скачал файл с сайта, открой его и выбери установку.
3. После установки открой новый терминал и выполни команду из следующего шага. Менеджер может установить среду Python при первом запуске команды; если появится запрос на установку, следуй подсказкам и дождись завершения.
4. Если менеджер предложит добавить каталог в `PATH`, помни: это необязательно для запуска через `py`; путь нужен для дополнительных команд, например `python3.15.exe`.

### Шаг 3. Проверь Python в Windows

Открой «Терминал», PowerShell или «Командную строку» через меню «Пуск». Выполни:

```powershell
py -3 --version
```

Нажми Enter. Если Python доступен, появится строка с версией, например `Python 3.x.x`. Буквы `x` здесь обозначают номер установленной версии.

Если вместо версии появляется `Can't find a default Python.`, Launcher не находит интерпретатор по умолчанию. Убедись, что Python install manager установлен, затем выполни `py install 3`, дождись завершения установки и снова проверь `py -3 --version`. Если команда `py install 3` выдаёт ошибку `can't open file` и в тексте упоминается `install`, вероятно, вызывается старый Python Launcher, который не поддерживает эту подкоманду. В Windows 11 открой «Установленные приложения» (Installed apps), а в Windows 10 — «Приложения и возможности» (Apps & features), найди **Python Launcher** и удали именно его, не удаляя установленные версии Python. Затем открой новый терминал и повтори проверку. Если команда не распознана, проверь, что установка менеджера завершилась, затем закрой и заново открой терминал. Если менеджер сообщает, что подходящая версия Python не установлена, выполни `py install 3`, дождись завершения установки и повтори `py -3 --version`. Если при выполнении команды `py install 3` появляется ошибка `can't open file` и в тексте упоминается `install`, вероятно, команда запускается через старый Python Launcher, который не поддерживает эту подкоманду. В Windows 11 открой «Установленные приложения» (Installed apps), а в Windows 10 — «Приложения и возможности» (Apps & features), найди **Python Launcher** и удали именно его, не удаляя установленные версии Python. Затем открой новый терминал и повтори `py -3 --version`. Если проблема остаётся, смотри [официальное руководство по устранению неполадок Python для Windows](https://docs.python.org/3/using/windows.html#troubleshooting).

## 3. Установка Python и VS Code в Ubuntu и Debian с `apt`

Названия программ и команды установки зависят от дистрибутива. Инструкции ниже предназначены для Ubuntu и Debian-подобных систем, использующих `apt`. Для Fedora, Arch Linux и других дистрибутивов команды могут отличаться: используй пакетный менеджер и документацию именно своей системы.

### Шаг 1. Проверь Python в Ubuntu и Debian-подобных Linux

В Ubuntu открой приложение «Терминал». В стандартном рабочем столе это обычно можно сделать сочетанием клавиш `Ctrl+Alt+T` или через поиск приложений: нажми клавишу `Super` (обычно с логотипом Windows), введи `Терминал` и открой найденное приложение. Если сочетание клавиш отличается в твоём окружении, воспользуйся меню приложений. Затем выполни:

```bash
python3 --version
```

Если команда выводит версию Python 3, переходи к шагу 2. Если Python отсутствует, в Ubuntu установи его командами:

```bash
sudo apt update
sudo apt install python3 python3-venv python3-pip
```

Система может запросить пароль пользователя. При вводе пароля символы на экране могут не отображаться — это нормально. Пакет `python3-venv` нужен для создания изолированных окружений Python, а `python3-pip` — для установки сторонних библиотек. В первой программе они не используются, но понадобятся в следующих уроках.

### Шаг 2. Установи VS Code в Linux

1. Открой [code.visualstudio.com](https://code.visualstudio.com/).
2. Выбери пакет или способ установки для своего дистрибутива.
3. Следуй актуальным инструкциям на официальном сайте.

### Шаг 3. Проверь Python после установки

В терминале выполни:

```bash
python3 --version
```

Убедись, что команда показывает версию Python 3.

## 4. Установка Python и VS Code в macOS

### Шаг 1. Установи VS Code в macOS

1. Открой [code.visualstudio.com](https://code.visualstudio.com/).
2. Скачай версию для macOS.
3. Распакуй архив, если это необходимо, и перемести Visual Studio Code в папку «Программы».
4. Запусти VS Code.

### Шаг 2. Установи Python в macOS

1. Открой [python.org/downloads](https://www.python.org/downloads/).
2. Выбери установщик для macOS и следуй его инструкциям.

Для обучения используй Python, установленный с python.org, а не системный Python macOS: системная версия предназначена для нужд операционной системы и не рассчитана на учебные эксперименты.

**Заверши настройку сертификатов:** после установки Python с python.org открой папку `/Applications/Python 3.x/` (вместо `3.x` используй номер установленной версии) и, если там есть файл `Install Certificates.command`, запусти его. Дождись завершения команды. Она настраивает сертификаты, которые могут понадобиться Python и `pip` для HTTPS-соединений.

### Шаг 3. Проверь Python в macOS

Открой «Терминал» через Spotlight и выполни:

```bash
python3 --version
which python3
```

Команда `which python3` показывает путь к интерпретатору, который запускается по команде `python3`. Для некоторых установок с python.org это может быть `/usr/local/bin/python3`, но путь зависит от версии установщика и конфигурации Mac. Если путь начинается с `/usr/bin/`, это системный Python macOS; для учебной работы проверь, что выбран Python, установленный с python.org.

Если `python3 --version` показывает версию Python 3, а `which python3` указывает на интерпретатор, установленный с python.org, переходи к следующему разделу.

**Возможная особенность macOS:** при первом запуске некоторых команд разработчика система может предложить установить Xcode Command Line Tools. Это системные инструменты разработчика. Если такое окно появилось, прочитай его текст и следуй официальным инструкциям Apple. Дождись завершения установки, затем снова выполни `python3 --version` и `which python3`. Если команда по-прежнему не работает, проверь сообщение об ошибке и следуй официальным инструкциям Apple. Не удаляй и не заменяй вручную системные компоненты Python.

## 5. Настройка VS Code для Python: расширение и интерпретатор

### Шаг 1. Установи расширение Python

1. Запусти VS Code.
2. Открой раздел Extensions («Расширения») в боковой панели.
3. Найди расширение **Python** от Microsoft.
4. Нажми Install («Установить»).

### Шаг 2. Выбери интерпретатор

Если VS Code не выбрал Python автоматически:

1. Открой палитру команд: `Ctrl+Shift+P` в Windows/Linux или `Cmd+Shift+P` в macOS.
2. Найди команду `Python: Select Interpreter`.
3. Выбери установленный Python 3.

Если нужный интерпретатор не появился, сначала проверь, что Python запускается в терминале. Затем перезапусти VS Code и повтори выбор интерпретатора.

## 6. Создаём проект `python-start` и файл `hello.py`

1. В файловом менеджере своей системы (например, Проводнике Windows или приложении «Файлы» в Ubuntu) создай папку `python-start`, например в папке «Документы». Запомни, где её создал.
2. В VS Code выбери **File → Open Folder** (Файл → Открыть папку) и укажи именно эту папку `python-start`, а не отдельный файл и не родительскую папку «Документы».
3. В боковой панели VS Code создай внутри открытой папки новый файл с названием `hello.py`.

Расширение `.py` используется для файлов с кодом Python.

## 7. Первая программа на Python: `print()` и кавычки

Вставь в файл `hello.py`:

```python
print("Привет, мир!")
```

Сохрани файл: `Ctrl+S` в Windows/Linux или `Cmd+S` в macOS.

`print()` выводит значение на экран. Кавычки обозначают текстовую строку: текст внутри кавычек выводится как есть, а сами кавычки в результате не появляются. Кавычки в коде обязательны, если мы хотим передать текст.

## 8. Как запустить программу на Python

В VS Code можно нажать кнопку запуска Python-файла (значок ▶, если он отображается над редактором). Также можно запустить программу из встроенного терминала через меню **Terminal → New Terminal**.

Сначала открой папку `python-start` в VS Code через **File → Open Folder** (Файл → Открыть папку), затем выбери **Terminal → New Terminal**. Встроенный терминал обычно открывается в папке проекта.

Проверь текущий путь в терминале:

- **Ubuntu/Linux и macOS:** выполни `pwd`.
- **PowerShell:** выполни `Get-Location`.
- **Командная строка Windows (`cmd.exe`):** выполни `cd`.

В пути должна быть папка `python-start`. Если проект сохранён в папке «Документы», используй команду для своей системы:

- **Linux:** `cd ~/Documents/python-start` или `cd ~/Документы/python-start`. Название каталога зависит от настроек системы; проверь его командой `ls ~`.
- **macOS:** `cd ~/Documents/python-start`.
- **PowerShell:** `cd "$HOME\Documents\python-start"`.
- **Командная строка Windows (`cmd.exe`):** `cd /d "%USERPROFILE%\Documents\python-start"`.

Если папка называется иначе или проект сохранён в другом месте, замени путь на фактический.

**Windows:**

```powershell
py hello.py
```

**Ubuntu/Linux и macOS:**

```bash
python3 hello.py
```

Ожидаемый результат:

```text
Привет, мир!
```

Если вывод совпал, программа запустилась успешно.

## 9. Если что-то не работает: частые ошибки

### Терминал не находит Python

- Windows: проверь командой `py -3 --version`.
- Ubuntu/Linux и macOS: проверь командой `python3 --version`.
- После установки закрой и заново открой терминал.
- Если VS Code не видит Python, перезапусти VS Code и выполни `Python: Select Interpreter`.

### Программа не запускается

Проверь, что:

- файл называется `hello.py`;
- файл сохранён;
- терминал открыт в папке проекта `python-start` (путь можно проверить командой `pwd` в Ubuntu/Linux и macOS, `Get-Location` в PowerShell или `cd` в `cmd.exe`);
- команда запуска соответствует твоей операционной системе;
- скобки и кавычки написаны правильно.

Правильный пример:

```python
print("Привет, мир!")
```

Если ошибка остаётся, скопируй её полный текст для разбора. Не публикуй пароли, токены или персональные данные в сообщениях об ошибках.

## 12. Частые вопросы (FAQ)

### Нужно ли устанавливать Python, если я уже установил VS Code?

Да, нужно. VS Code — это редактор, в нём нет самого Python. Расширение Python тоже не включает интерпретатор: оно только добавляет поддержку языка в редактор.

### Какую версию Python выбрать новичку?

Подойдёт любая актуальная версия Python 3, которую предлагает python.org по кнопке скачивания. Для этого урока конкретный номер версии не важен: все команды работают одинаково.

### Почему в Windows используется команда `py`, а в Linux и macOS — `python3`?

В Windows Python install manager предоставляет команду `py` для запуска Python и выбора версии. Её иногда называют **лаунчером**: это программа-посредник, которая находит нужный интерпретатор и запускает его. В новых установках команду `py` предоставляет менеджер Python; на старых установках её мог предоставлять отдельный Python Launcher. Если команда `py install 3` выводит `can't open file` и упоминает `install`, возможно, `py` запускает старый **Python Launcher**. Удали именно Python Launcher через «Установленные приложения» (Windows 11) или «Приложения и возможности» (Windows 10), не удаляя сами версии Python. Если подходящая версия Python ещё не установлена и менеджер поддерживает команду `install`, выполни `py install 3`, а затем снова проверь `py -3 --version`. В Linux и macOS обычно используют команду `python3`; команда `python` там может отсутствовать или указывать на другую версию.

### Что делать, если после установки терминал всё равно не находит Python?

Закрой и заново открой терминал: он читает настройки системы при запуске. Если VS Code был открыт во время установки, перезапусти и его, затем выбери интерпретатор командой `Python: Select Interpreter`.

### Нужны ли права администратора?

Не всегда. Python install manager обычно можно установить для текущего пользователя, но доступные варианты зависят от способа установки и настроек устройства. Установщик Python для macOS может запросить пароль администратора в зависимости от выбранного способа установки и места назначения. Для установки системных пакетов в Ubuntu используется `sudo`, поэтому может потребоваться пароль пользователя с соответствующими правами. Если устройство управляется организацией, следуй её правилам установки программ.

### Можно ли выполнить этот урок в онлайн-редакторе без установки?

Нет. Цель урока — настроить собственную среду и запустить программу локально, поэтому установка VS Code и Python обязательна.
