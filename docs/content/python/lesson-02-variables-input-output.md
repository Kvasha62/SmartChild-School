## 2. Переменные: сохраняем значения

Переменная — это имя, с помощью которого программа обращается к значению. Создадим две переменные:

```python
name = "Аня"
age = 12

print(name)
print(age)
```

Ожидаемый вывод:

```text
Аня
12
```

Знак `=` в таком выражении присваивает переменной значение. Он не означает «равно» в математическом сравнении.

В примере:
- `name` хранит текст `"Аня"`;
- `age` хранит целое число `12`;
- `print()` выводит значения на экран.

Имена переменных чувствительны к регистру: `age` и `Age` — разные имена. Выбирай названия, которые объясняют назначение значения: `student_name`, `score`, `price`.

### Правила имён

- Имя может содержать латинские буквы, цифры и символ подчёркивания `_`.
- Имя не может начинаться с цифры.
- Пробелы в имени не используются.
- Нельзя использовать зарезервированные слова Python, например `if` или `for`.
- Обычно имена переменных пишут в нижнем регистре, разделяя слова подчёркиванием: `user_name`.

Пример корректных имён: `city`, `lesson_2`, `total_price`.

Примеры некорректных имён: `2lesson`, `user name`, `for`.

## 3. Основные типы данных

На этом этапе достаточно знать четыре часто используемых типа.

| Тип | Для чего нужен | Пример |
| --- | --- | --- |
| `int` | Целое число | `12`, `-3` |
| `float` | Число с дробной частью | `3.14`, `-0.5` |
| `str` | Текстовая строка | `"Привет"`, `"123"` |
| `bool` | Логическое значение | `True`, `False` |

Посмотри на пример:

```python
age = 12
height = 1.5
name = "Аня"
is_student = True

print(type(age))
print(type(height))
print(type(name))
print(type(is_student))
```

Ожидаемый вывод:

```text
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
```

Функция `type()` помогает узнать тип значения. Обрати внимание: `"12"` — это строка, потому что число заключено в кавычки, а `12` — целое число.

## 4. Выводим значения с помощью `print()`

Можно вывести несколько значений за один вызов:

```python
name = "Аня"
score = 8

print("Имя:", name)
print("Баллы:", score)
```

Ожидаемый вывод:

```text
Имя: Аня
Баллы: 8
```

Python разделяет аргументы `print()` пробелом по умолчанию. Для простого объединения текста и переменных можно использовать f-строку:

```python
name = "Аня"
score = 8

print(f"Ученик {name} набрал {score} баллов.")
```

Ожидаемый вывод:

```text
Ученик Аня набрал 8 баллов.
```

В f-строке перед кавычками стоит буква `f`, а значения переменных вставляются внутрь фигурных скобок `{}`.

## 5. Получаем данные с помощью `input()`

Функция `input()` показывает приглашение и ждёт, пока пользователь введёт текст и нажмёт Enter:

```python
name = input("Как тебя зовут? ")
print(f"Привет, {name}!")
```

Например, если ввести `Оля`, программа выведет:

```text
Как тебя зовут? Оля
Привет, Оля!
```

Важно: **`input()` возвращает строку (`str`), даже если пользователь ввёл цифры.**

Проверим:

```python
age = input("Сколько тебе лет? ")
print(type(age))
```

Если ввести `12`, тип всё равно будет `str`. Чтобы выполнять арифметические операции, текст нужно преобразовать в число.

## 6. Преобразуем строки в числа

Для преобразования используются:
- `int()` — преобразует подходящую строку в целое число;
- `float()` — преобразует подходящую строку в число с дробной частью.

Пример с целыми числами:

```python
first_text = input("Введи первое целое число: ")
second_text = input("Введи второе целое число: ")

first_number = int(first_text)
second_number = int(second_text)

print("Сумма:", first_number + second_number)
```

Если ввести `7` и `5`, результат будет:

```text
Введи первое целое число: 7
Введи второе целое число: 5
Сумма: 12
```

Для числа с дробной частью используй точку в качестве десятичного разделителя:

```python
price = float(input("Введи цену: "))
print("Цена после увеличения на 1:", price + 1)
```

Например, ввод `2.5` даст результат `3.5`.

Если вместо числа ввести произвольный текст, например `семь`, преобразование через `int()` завершится ошибкой `ValueError`. Пока просто проверь, что вводишь число в ожидаемом формате. Обработку таких ошибок изучим позже.

## 7. Арифметические операции

С числами можно выполнять основные действия:

| Оператор | Действие | Пример | Результат |
| --- | --- | --- | --- |
| `+` | Сложение | `7 + 5` | `12` |
| `-` | Вычитание | `7 - 5` | `2` |
| `*` | Умножение | `7 * 5` | `35` |
| `/` | Деление | `7 / 2` | `3.5` |
| `//` | Целочисленное деление | `7 // 2` | `3` |
| `%` | Остаток от деления | `7 % 2` | `1` |
| `**` | Возведение в степень | `2 ** 3` | `8` |

Попробуй запустить:

```python
number = 17

print("Частное:", number // 5)
print("Остаток:", number % 5)
```

Ожидаемый вывод:

```text
Частное: 3
Остаток: 2
```

## 8. Мини-проект: калькулятор суммы

Собери изученные элементы в одной программе. В файле `lesson_02.py` напиши:

```python
first_number = float(input("Введи первое число: "))
second_number = float(input("Введи второе число: "))

total = first_number + second_number

print(f"Сумма: {total}")
```

Пример запуска:

```text
Введи первое число: 2.5
Введи второе число: 4
Сумма: 6.5
```

Здесь программа получает две строки, преобразует их в числа типа `float`, сохраняет результат сложения в переменной `total` и выводит его.

Чтобы проверить себя, попробуй другие значения, например `10` и `-3`. Для этого примера вводи числа с точкой, если нужна дробная часть.

## 11. Частые ошибки

### Ошибка 1. Сложение строк вместо чисел

Код:

```python
first = input("Первое число: ")
second = input("Второе число: ")
print(first + second)
```

Если ввести `2` и `3`, программа выведет `23`, потому что объединит две строки. Для арифметического сложения преобразуй значения:

```python
print(int(first) + int(second))
```

### Ошибка 2. Забыли кавычки вокруг текста

Неправильно:

```python
name = Аня
```

Правильно:

```python
name = "Аня"
```

Текстовые значения нужно заключать в кавычки.

### Ошибка 3. Использовали запятую вместо точки в дробном числе

В Python десятичная часть числа обычно отделяется точкой: `2.5`, а не `2,5`. Если использовать запятую при вводе в `float()`, преобразование не сработает.

### Ошибка 4. Ввели нечисловое значение

`int("привет")` вызывает `ValueError`, потому что текст нельзя преобразовать в целое число. Вводи данные в соответствии с подсказкой программы.
