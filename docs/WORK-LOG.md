# Журнал работ AI-исполнителей

Журнал фиксирует историю действий, а не утверждает решения владельца.
Добавляйте новые записи сверху, не переписывая предыдущие. Для задач,
подлежащих Issue/PR-процессу, сохраняйте ссылки и статусы по
[протоколу координации](coordination.md). Не помещайте сюда секреты,
персональные данные или реальные данные детей.
