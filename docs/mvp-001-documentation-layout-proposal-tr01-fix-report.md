## 3. Исправленная формулировка

**Было (строка 332):**

```
- созданы только два файла: этот документ `docs/mvp-001-documentation-layout-proposal.md` и отчёт об устранении замечаний `docs/mvp-001-documentation-layout-proposal-review-response.md`.
```

**Стало (строка 332):**

```
- созданы только этот документ `docs/mvp-001-documentation-layout-proposal.md`, отчёт об устранении замечаний `docs/mvp-001-documentation-layout-proposal-review-response.md` и отчёт о повторном исправлении `docs/mvp-001-documentation-layout-proposal-review-response-followup.md` — всего три файла; иных файлов в [PR #14][pr14] нет. Состав совпадает с разделом 6 [отчёта о повторном исправлении](mvp-001-documentation-layout-proposal-review-response-followup.md).
```

### Почему не ограничились заменой числа

Замена «два» на «три» устранила бы ложность, но сохранила бы причину дефекта: число, не привязанное к проверяемому источнику. Новая формулировка содержит три элемента проверяемости:

1. **перечисление файлов** — состав сверяется поимённо, а не по счётчику;
2. **утверждение об отсутствии иных файлов в PR #14** — проверяется по перечню файлов PR;
3. **перекрёстная ссылка на раздел 6 отчёта о повторном исправлении** — два документа обязаны измениться согласованно, рассогласование обнаруживается.

Числительное «три» оставлено намеренно: критерий устранения TR-01 требует, чтобы число и состав файлов в разделе 8 совпадали с перечнем файлов PR.

## 5. Почему отчёт об исправлении размещён в отдельном PR

Отчёт не включён в PR #14 сознательно. Добавление четвёртого файла в PR #14 сделало бы утверждение «всего три файла; иных файлов в PR #14 нет» ложным **в том же коммите, который его исправляет**. Размещение отчёта в отдельном PR сохраняет PR #14 объёмом три файла — ровно тем, который раздел 8 и утверждает.

Это согласуется со сложившейся практикой репозитория: артефакты ревью ([PR #15][pr15], [PR #16][pr16], [PR #17][pr17], [PR #18][pr18]) публикуются отдельными PR, а в PR #14 вносятся только сам документ и отчёты об устранении.
