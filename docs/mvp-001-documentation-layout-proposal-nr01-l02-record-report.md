## 6. Статус записи и что требуется для перевода в `принято`

Текущий статус — **`предложено`** (внесён в таком виде). Для перевода в `принято` требуется отдельное явное действие владельца в этом PR:

1. решение владельца, явно относящееся к полному SHA версии записи (`docs/decisions/README.md`, п. 4; `docs/coordination.md`, «Принятие результата», п. 4);
2. после этого — замена статуса на `принято` со ссылкой на доказательство согласования (`docs/decisions/README.md`, п. 6);
3. подтверждение относится к полному SHA: если запись будет обновлена новым коммитом, прежнее подтверждение автоматически не переносится.

До выполнения этих действий запись считается предложенной; слияние выполняется только по явному решению владельца (`CONTRIBUTING.md`, п. 9).
