### Уточнение к L-02 (а)

Вариант (а) в документе сопровождается оговоркой «содержание ревью теряется (прецедент [PR #13][pr13])». Для ревью, проведённых **в GitHub**, эта оговорка не действует: закрытый PR сохраняется в репозитории неограниченно, и его содержимое воспроизводимо по номеру. Прецедент PR #13 возник потому, что то ревью выполнялось **вне GitHub** и никогда не попадало в PR. Следовательно, выбранный принцип закрывает пробел §4.4 для всех ревью, проводимых в GitHub, и не требует создания каталога `reviews/`.
