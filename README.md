# SmartChild

SmartChild is an educational platform for programming education and preparation for the Russian ОГЭ and ЕГЭ exams.

## Project status

The repository is being initialized. The initial bootstrap establishes the project's documentation, development workflow, review rules, and coordination process before product implementation begins.

## Working principles

- Changes are delivered through pull requests after repository initialization.
- Every task has explicit acceptance criteria.
- Reviews apply to a specific commit SHA.
- Decisions and architecture changes require owner approval.
- No secrets, access tokens, personal data, or real children's data may be committed.
- Synthetic data must be used in tests and examples.
- Product implementation begins only after the bootstrap process is approved.

## Documentation

Project documentation and the development process will be added as part of the bootstrap pull request.

## Security

Do not commit credentials, secrets, personal information, real children's data, or assets without appropriate rights.
